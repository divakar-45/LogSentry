# LogSentry

A desktop-based Security Operations Center (SOC) Log Analyzer built with Java Swing.

## Features

- Import Security Logs
- Parse Log Entries
- Dashboard
- Status Bar
- MVC Architecture
- Java Swing UI

## Technologies

- Java
- Java Swing
- Git
- GitHub
