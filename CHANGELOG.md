# Development Methodology

LogSentry has been developed using an incremental sprint-based methodology.

Each sprint followed the same workflow:

```

Requirement Analysis

↓

Feature Design

↓

Implementation

↓

Compilation

↓

Testing

↓

Debugging

↓

Git Commit

↓

Next Sprint

```

This approach ensured that every feature was validated before introducing new functionality.
